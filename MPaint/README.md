# Canvas Drawing App

A clean, interactive HTML5 canvas application built to draw sketches directly in your web browser.

## Features

* **Interactive Sketching:** Smooth mouse-controlled drawing tools.
* **Responsive Layout:** The canvas adapts dynamically to window resizing.
* **Undo/Redo History:** Use `Ctrl + Z` to undo and `Ctrl + Y` to redo changes.

## Setup Instructions

No complex compilation is needed. To run this project locally:

1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser, such as Chrome, Firefox, Safari, or Edge.

## Technologies Used

* HTML5 Canvas API
* Vanilla JavaScript
* Custom CSS
